## Decisions
- Handles share `Rc<RefCell<Shared>>` with the spawner: spawner drop kills+reaps
  all live; late handle drops observe the reaped set (no double reap).
- IDs monotonic per spawner (`next_id += 1`), never reused; deterministic.
- `SpawnRequest::new` does not validate; `Spawner::spawn` validates first,
  then cap-checks before any port call, so SpawnFull leaves table byte-identical.
- Startup failure path (port `await_startup` err) kills+reaps the partial child
  inside `spawn`, returning count to the pre-attempt value.
- `Spawner`/`ChildHandle`/`SpawnRequest` Debug emit counts/ids/kinds only;
  `SpawnError` carries no strings — clean by construction.
- Control-byte argv/dir rejected (covers NUL plus \n\t); bounds
  argv 1..=32 x 1..=1024 chars, dir 1..=1024 chars.
