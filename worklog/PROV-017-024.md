## Decisions

- One-line product fix, not a test weakening: the percent-encoded redirect
  `http%3A%2F%2F127.0.0.1%3A...` failed the module's own boundary rule (the
  `before` byte of `127.0.0.1` was `f` from `%2F`, not an allowed delimiter).
  Emitting the raw `http://127.0.0.1:1455/oauth/callback` constant satisfies
  https-origin + loopback-redirect rules. `begin_login_with_url` still accepts
  raw loopback URLs from callers.
- PROV-021 deviation recorded: the module requires provider pre-registration
  (`UnknownProvider` on unregistered record) while the card text omits that
  error; tests register providers first and isolate the single remaining new
  key as `Overflow` at 256 entries. Saturating arithmetic verified at
  `u64::MAX`.
- PROV-023 `catalog_version` vs card `version` spelling: file uses
  `catalog_version: "1"` (accepted by T01 as the version field); content
  contract otherwise exact.
- PROV-024 has no product-code diff helper (`diff_shapes` is specified as a
  test-side comparison); the differential check lives in the frozen test and
  compares header-name sets + endpoint shapes of the committed fixtures.
- Memory: 1.8 GiB available at start; ran one cargo command at a time with
  `CARGO_BUILD_JOBS=2 RUST_TEST_THREADS=2`, `timeout 120`, per contract.
