## Contract and implementation

`Renderer` remains the sole owner of a live native handle and is non-Send/non-Sync.
Creation rejects zero dimensions and invalid native handles; every operation
fail-closes on a closed handle or invalid dimensions. Text and snapshots retain
their existing bounded byte caps. Terminal restoration is now state-scoped:
the wrapper records successful setup and only invokes `restoreTerminalModes` for
terminal state it initialized, while Drop disables only input modes enabled by
the wrapper before destroying the handle. Repeated explicit restore/disable and
Drop are idempotent, and close invalidates the handle before releasing CLAIMED.

made. The CLI caller remains outside this lease; the next integration lane owns
