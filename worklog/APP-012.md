## Observable contract (RED, scoped)

terminal (macOS `/usr/bin/script`), must surface the documented in-app setup

fails on exactly that one assertion.

Failure states:
- `OC2_TEST_BINARY` missing/not a file/not executable -> prerequisite failure,
  never RED.
- `--version` timeout/exit/identity failure -> prerequisite failure.
- owned `serve` never healthy, or has descendants -> prerequisite/cleanup
  failure.
- installed client timeout, output overflow, undrained reader -> fixture
  failure (reported distinctly).
- missing setup marker -> the intended RED failure.

## Fixture safety (the critical repair)

The previous draft read the descriptor `pid` then sent TERM then KILL to that
arbitrary PID, with a bounded-but-blind 3s wait. Removed entirely.

Replacement: the test spawns its OWN `oc2 serve` child and holds the
`std::process::Child` handle. `OwnedDaemon::drop` kills and reaps ONLY that
handle. It never parses a descriptor PID and never calls `/bin/kill`. The owned
daemon is asserted to have zero descendants (`/usr/bin/pgrep -P <child>`), so a
single-handle kill is provably sufficient. Reader threads report over an
`mpsc::Receiver` and the test waits with `recv_timeout(3s)` instead of an
unbounded `join`, so a retained pipe cannot hang the test.

bounded `/usr/bin/script`, one owned `serve` child (verified no descendants).
