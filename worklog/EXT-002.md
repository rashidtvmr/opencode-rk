## Contract decisions

- `BUILTINS = [("core.commands", &[]), ("core.skills", &["skill.list"])]` (exactly 2 entries, 0..=4 caps each). `register_builtins(reg, version)` validates version first, pre-checks `len + 2 > MAX_PLUGINS` for overflow atomicity, adds in table order, rolls back on first failure, then `mark_ready`s each; returns ids in table order. `unregister_builtins` removes in order, counts removed, skips unknown. `is_builtin` exact match. Second register without unregister => `Duplicate`; register->unregister->register => fresh larger ids. Feature-off path: `register_builtins` never called, zero cost.
- Caps inherit EXT-001 values (64/16/128/64).
