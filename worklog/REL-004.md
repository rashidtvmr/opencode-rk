# REL-004 worklog

## Claim

Implement a bounded per-turn telemetry counter schema for token usage, API time, code-line changes, web-search requests, and unknown model pricing state. The slice only records counts supplied by runtime callers; it does not invent or fetch model prices.

## Source evidence

- Candidate base revision: `accb2e919fe3e02ac34aa4b42851ec710f8ca282`.
- `tasks/REL-004.md`: REQ-016, five test obligations.

## Decisions

- Use saturating integer counters for tokens, milliseconds, lines and request counts so aggregation cannot wrap.
- Unknown price is sticky across aggregation: once any contributing model cost is unknown, the aggregate remains marked unknown.
- Keep monetary cost as caller-supplied micro-USD integer units; this slice does not own pricing lookup or floating-point rounding.
- No queue, retained per-request log, async task, network call, or clock dependency is introduced.
- `record` saturates every numeric counter independently and ORs the unknown-cost flag, so a later known-cost turn cannot erase an earlier pricing gap.
