## DDL freeze status (DECISIVE)

The approved contract (`APP012-INTEGRATION-CONTRACT.md`) names the two tables
and their key columns but explicitly says at lines 101-103: "Names/schema are
proposal terms to freeze". Its API section (lines 66-69) fixes the semantic
names `round_id`, `session_id`, `turn_message_id`, `round_ordinal`,
`expected_calls`, `pair_index`, `kind`, `call_id`, `name`.

External storage artifacts disagree on the parts the contract does NOT fix:

- `APP012-storage-contract-final.md` SHA `3150a5f3...`:
  `typed_tool_records(... call_id ... length(CAST(call_id AS BLOB)) BETWEEN 1
  AND 512 ... payload TEXT ... byte_len ...)`, `tool_rounds(... expected_pairs
  ...)`.
- `APP012-typed-history-contract-reconciled.md` SHA `0?`:
  `typed_tool_records(... inline_text TEXT, blob_hash TEXT ...)`,
  `tool_rounds(... expected_calls ...)`.
- `APP012-typed-history-schema-proposal.md` / `schema-reviewed.md`:
  `feature_migrations(feature, applied_at)` (NO version column),
  `typed_tool_records` keyed by `(message_id, seq)`.

Two hard contradictions:

1. The latest storage DDL (`storage-contract-final.md`) contains a
   `call_id ... BETWEEN 1 AND 512` cap. The approved contract lines 28-31 and
   the registered DB-021 card explicitly FORBID any 512-byte call-ID cap
   ("no arbitrary 512-byte call-ID cap is introduced"). No reviewed DDL that
   includes the cap can be frozen.
2. Payload column shape (`payload TEXT` vs `inline_text`/`blob_hash` vs
   `arguments`/`output`) and the feature-ledger columns (`version` present or
   absent) are not agreed.

Per the DB-021 registered card obligation 5 escape clause and the delegation
instruction ("if contract names/columns not actually fixed stop exact ambiguity
before fabricating frozen DDL"), byte-behavior tests are NOT bound to an
invented column shape. The test artifact binds only identifiers the approved
contract itself fixes (table names + key columns) and asserts the contract's
DDL byte semantics structurally (BLOB casts present, no 512 upper bound) so the
integrator can freeze the payload/ledger columns without the lane inventing
observability.
