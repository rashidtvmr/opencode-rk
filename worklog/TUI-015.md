## Contract and fixture

Five parent tests invoke the exact current test executable through Python 3 stdlib
PTY supervision. The child receives `TUI015_CHILD=1` and one exact child test name,
uses only the public bridge API, and never recursively invokes Cargo. Python owns the
slave descriptor, records termios before/after, bounds output at 1 MiB and runtime at
8 seconds, uses a temporary HOME/cwd, and reaps the process group in all paths.
The non-native binary has an explicit failing test, preventing cfg-gated zero-test
success. The requested native run is intentionally not executed in this source-only
lane due to the controller's DB-019 heavy-slot reservation and native artifact policy.
