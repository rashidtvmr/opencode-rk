## Decisions
- Sends do not dequeue; only `ack(seq)` removes — matches "unacked events survive reconnect" (§State).
- `next_seq` assigned in push starting 1, saturating, never 0.
- `dispose` + `Drop` both clear bytes and close handle once (`closed` flag); dispose idempotent.
- backoff via `checked_shl` (no `saturating_shl` on this toolchain) + min cap; `failures` counter saturating_add.
- Test uses `#[path]` include to honor "never edits shared lib.rs" lock.
