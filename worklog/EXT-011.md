## Decisions

- Load-bearing defect found and fixed in this lease
  (`crates/tools/src/plugin_transform.rs`, +13/-4, `git diff --check` clean):
  `set_scope_disabled(scope, true)` on an unknown scope pushed a ghost
  entry into `disabled`, violating the task's "no-op" clause and the
  "no unbounded queue" rule (`disabled` grew without bound over distinct
  unknown scopes; probe showed `disabled: [9999]` with zero entries, and a
  later `add` for that scope was wrongly suppressed). Fix: record the scope
  only when `entries` already contain it, restoring the documented
  invariant `disabled.len() <= entries.len() <= EXT11_MAX_TRANSFORMS`
  (now stated on the struct). Doc-only touch: "seq order" -> "insertion
  order" to match vec-order replay. Behavior otherwise unchanged; all
  frozen assertions still pass.
- `ext_replay_lane.rs` (fallback lane copy) already carried this guard;
  canonical file now byte-identical to it (`diff` clean).
- No cross-lane edits: pre-existing dirty files (`share_merge.rs`,
  `share_queue.rs`, `mcp_transport.rs`) untouched.
