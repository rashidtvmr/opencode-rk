## User-observable outcome

A pure, offline, redacted provider-interaction replay checker: given a caller-
supplied in-memory cassette (ordered request/response frames with secrets
already redacted by the caller) it replays frames in order, enforces ordered
matching, and reports pass/fail plus the first mismatch without performing any
live network I/O, filesystem access, or environment reads. UI/CLI and provider
tests can verify a recorded session deterministically. This is the in-memory
replay nucleus only; cassette persistence, live recording transport,
`CI`/environment policy, environment-secret scanning, and WebSocket streaming
stay explicitly out per `sources/operations-ownership-gap.json` and the
DISC-003 provider-recording reconciliation.

## Observable contract

- `Frame { request: String, response: String }` (both caller-redacted; empty request rejected at push).
- `Cassette { frames: Vec<Frame> }`: `Cassette::new()`, `push_frame(req, res)
  -> Result<(), ReplayError>`; `len()`, `is_empty()`.
- `ReplayError::EmptyRequest`, `ReplayError::TooManyFrames { max, actual }`,
  `ReplayError::Mismatch { index, expected: String, actual: String }`,
  `ReplayError::Exhausted { index }` (request past end), `ReplayError::UnusedFrames { remaining }` (strict mode tail).
- `MAX_FRAMES: usize = 1024`; `MAX_FRAME_BYTES: usize = 65536`
  (mirrors resource-targets `maxInMemoryPreviewBytesPerTool`; any single
  request/response over cap => `TooManyFrames`-style refusal via
  `ReplayError::TooManyFrames` before push; exact variant asserted in T03).
- `replay(cassette, requests: &[&str], strict: bool) -> Result<usize, ReplayError>`:
  ordered matching; returns count matched; `strict=true` requires exact length
  (`UnusedFrames` on tail); `strict=false` allows prefix match.
- Deterministic: same cassette + requests => same verdict; no wall-clock, no
  env, no I/O.
- Suggested module boundary: NEW file `crates/foundation/src/ops_replay.rs`
  (pure functions only). Worker ships additive fragment only, never edits
  shared `lib.rs`, `Cargo.toml`, schemas, migrations. Integrator wires `pub mod`.

## Failure states

- Empty request string pushed: `Err(ReplayError::EmptyRequest)`; cassette unchanged.
- Over `MAX_FRAMES` or any frame over `MAX_FRAME_BYTES`: push refused with
  `Err(ReplayError::TooManyFrames { .. })`; cassette keeps prior frames only.
- Request mismatch at index i: `Err(ReplayError::Mismatch { index: i,
  expected, actual })`; no further matching attempted.
- Request past end: `Err(ReplayError::Exhausted { index: len })`.
- Strict-mode tail: `Err(ReplayError::UnusedFrames { remaining })`.
- Secret safety: frames are caller-redacted opaque strings; this module never
  scans env, never logs frame bodies (mismatch reports carry index + lengths
  only, asserted in T05), never writes cassettes to disk, never opens network.
  No SQLite/OpenCode DB writes. No changes to the user's existing OpenCode
  database; tests use inline fixture strings only.

## Resource bounds

- Count cap `MAX_FRAMES`, byte cap `MAX_FRAME_BYTES` per frame; bounded
  `Vec`, no streaming retention beyond the cassette; no unbounded queue, no
  unbounded retained output.
- O(n) time in frame/request count, O(1) extra beyond inputs; no thread, no
  task spawn, no detached work; caller owns cassette lifetime; cancel path is
  the caller's (drop the slice), nothing to reclaim here.

## Test obligations (frozen)

- OPS-009-T01 (happy path): 3-frame cassette replays 3 matching requests =>
  `Ok(3)`; strict and non-strict both pass on exact length; `len() == 3`,
  `!is_empty()`.
- OPS-009-T02 (determinism + order): repeated `replay` same inputs =>
  identical verdict; out-of-order requests => `Mismatch { index: 1, .. }`;
  prefix of 2 on 3-frame cassette => non-strict `Ok(2)`, strict
  `UnusedFrames { remaining: 1 }`.
- OPS-009-T03 (caps refuse): 1025th push => `TooManyFrames`; 65537-byte
  request or response => push refused; 1024-frame cassette replays within
  bounds without OOM.
- OPS-009-T04 (failure states): empty request => `EmptyRequest`; request past
  end => `Exhausted { index: len }`; mismatch carries correct index/expected/
  actual; failed replay mutates nothing (cassette byte-identical).
- OPS-009-T05 (redaction + isolation): mismatch error contains index + lengths
  only, zero frame-body bytes (assert on `format!("{:?}", err)`); no test
  touches network, filesystem, env, or any DB; decoy secret string in a frame
  is never emitted to logs (captured output assert).
