# CAT-004: Plugin Cache with LRU Eviction

## Goal
Implement plugin cache with LRU eviction in `crates/catalog/src/cache.rs`.

## Scope
- `CacheEntry` struct with key, value (JSON), hits u64, created_at, last_accessed
- `CatalogCache` with entries HashMap, capacity, evict_order Vec for LRU
- Methods: `new(capacity)`, `get(key)->Option<&Value>`, `set(key, value)`, `evict(key)`, `clear()`, `stats()->(hits, misses)`
- LRU eviction on access and insert when capacity exceeded

## Implementation

### Files Modified
- `crates/catalog/src/cache.rs` - Full implementation
- `crates/catalog/src/lib.rs` - Added `pub mod cache;`

### API
```rust
pub struct CacheEntry {
    pub key: String,
    pub value: Value,
    pub hits: u64,
    pub created_at: SystemTime,
    pub last_accessed: SystemTime,
}

pub struct CatalogCache {
    entries: HashMap<String, CacheEntry>,
    evict_order: Vec<String>,  // front = most recent
    capacity: usize,
    hits: u64,
    misses: u64,
}
```

## Tests (5)
1. `get_miss_returns_none` - Get on missing key returns None, increments misses
2. `set_and_get` - Set value, get returns it, increments hits
3. `lru_eviction` - When capacity exceeded, evicts least recently used
4. `clear_removes_all` - Clear removes all entries and resets stats
5. `hits_counted` - Multiple hits and misses counted correctly
