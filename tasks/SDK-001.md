## User-observable outcome

Callers driving the SDK over one caller-supplied base URL observe typed HTTP calls: GET/POST requests carry the workspace directory both as an `x-workspace-directory` header and a `?directory=` query rewrite, responses decode to typed bodies under a 30s timeout, injected aborts cancel in-flight calls with reclaimed resources, and every typed error plus every log line is free of secret bytes. No process spawn, no ambient network beyond the fixture harness, no persistence.

## Observable contract

- `SdkClient::new(base_url: &str) -> Result<SdkClient, SdkError>`: base URL max 2048 chars, http/https only; caller-supplied; bad scheme/empty/oversize => `Err(InvalidBaseUrl)`.
- `get(&self, path: &str, dir: &str, http: &dyn HttpPort, abort: &AbortFlag) -> Result<TypedBody, SdkError>`: typed GET against `base_url + path`.
- `post(&self, path: &str, dir: &str, body: &[u8], http: &dyn HttpPort, abort: &AbortFlag) -> Result<TypedBody, SdkError>`: typed POST with body max 1 MiB.
- Directory rewrite: every request sends header `x-workspace-directory: <dir>` and appends `?directory=<pct-encoded dir>` (or `&directory=` when a query exists); dir 1..=1024 chars, no control bytes.
- `HttpPort`/`AbortFlag` are caller-supplied traits (fixture harness in tests); this module performs no direct socket I/O and spawns no process.
- `SdkError { InvalidBaseUrl, BadStatus { status }, Decode, Timeout, Abort, TooLarge, InvalidInput }`: BadStatus carries only the numeric status, never the body.
- Bounds as explicit public constant: `SDK_TIMEOUT_SECS: u64 = 30` enforced by the caller port (deadline, not a sleep owned here).
- Deterministic: same base URL plus same fixture transcript plus same calls => byte-identical requests and results; no wall-clock, no globals.
- Suggested module boundary: `crates/server/src/sdk_client.rs` owning SdkClient, TypedBody, SdkError, HttpPort, AbortFlag, SDK_TIMEOUT_SECS, get, post, directory rewrite; shared lib.rs wiring left to integrator.
- Explicitly excluded: process/TUI spawning (SDK-002), ACP framing (ACP-001), auth/token storage, retries/backoff, actual socket I/O (caller port owns FDs).

## State and persistence transitions

- Client: stateless over the base URL; `new` validates only; get/post perform no retained state change by construction.
- Request lifecycle: built (headers plus rewritten URL) -> sent via port -> decoded or typed-error; failed calls leave no retained body in the module.
- Abort: `abort.flag()` before or during a call => `Err(Abort)`; port reclaims the in-flight slot; nothing retained.
- Persistence: none; bodies live in caller memory only.

## Failure states

- Bad base URL (empty/oversize/unsupported scheme): `Err(SdkError::InvalidBaseUrl)`; no request built, no port call.
- Non-2xx status: `Err(SdkError::BadStatus { status })` carrying the code only; body dropped, never surfaced.
- Malformed body on decode: `Err(SdkError::Decode)`; nothing retained.
- Deadline exceeded: `Err(SdkError::Timeout)`; in-flight slot reclaimed by the port.
- Injected abort: `Err(SdkError::Abort)`; in-flight slot reclaimed, queue unchanged.
- Oversize request body (> 1 MiB) or bad dir (empty/oversize/control bytes): `Err(SdkError::TooLarge)` / `Err(SdkError::InvalidInput)`; no port call.
- Unchanged-state guarantees: every error above leaves caller-visible client state byte-identical to before (no partial request retained).
- Secret safety: errors and logs carry variant names, paths, and status codes only, never bodies, tokens, or URLs with embedded secrets. Tests use fixture URLs/bodies only.

## Resource bounds

- Body caps: request body max 1 MiB, response body max 1 MiB; rejected before retention (no unbounded queue/output).
- URL/dir caps: base URL 2048 chars, dir 1024 chars, path 1024 chars; over-cap rejected before any port call.
- Owner/cancel path: caller owns the client, port, abort flag, and all sockets; calls are synchronous on the port, spawn no thread; abort plus drop reclaims the slot immediately; no detached task, no background poller, no process handle.
- Zero hidden cost: `new()` allocates only the validated base URL; idle cost is the caller-owned struct only.
