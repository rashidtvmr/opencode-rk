## User-observable outcome

Offline installation version/channel metadata normalization plus explicit-input
runtime path derivation for one host. Pure computation: parse version/channel
strings, derive XDG-style data/cache/config paths from caller-supplied base
dirs. No filesystem mutation, no process-environment read, no lock creation, no
network. Covers only the reviewed `installation/version.ts` slice plus path
derivation with injected inputs; the unreviewed installation remainder,
import-time directory creation, npm-config environment read and global-lock
configuration are explicitly out of scope.

## Observable contract

- `VersionMeta { version: String, channel: Channel }`; `Channel = Stable | Dev
  | Custom(String)`.
- `BaseDirs { data_dir: RelPath, cache_dir: RelPath, config_dir: RelPath }`
  (caller-supplied, already validated; no env lookup inside).
- `parse_version(raw: &str) -> Result<VersionMeta, VersionError>`;
  `derive_paths(meta: &VersionMeta, base: &BaseDirs) -> DerivedPaths
  { data_dir, cache_dir, config_dir, version_file: RelPath }`
  (`version_file = data_dir.join("installation").join("version")` shape;
  construction only, no creation).
- Deterministic: same inputs => byte-identical outputs; no wall-clock, no env,
  no I/O.
- Suggested module boundary: `crates/ops/src/install_meta.rs` (new module in
  existing ops crate if present, else `crates/foundation/src/install_meta.rs`
  as additive file). Worker ships additive fragment only, never edits shared
  `lib.rs`, `Cargo.toml`, schemas, migrations.
- Excluded and must fail closed if attempted: directory creation, env read,
  lock path configuration, npm-config loading, network fetch of versions,
  accepted BASE-004/005/006/007/008 behavior, frozen INT-002/OPS-007/OPS-009
  contracts.

## Failure states

- Empty/overlong raw (`len == 0 || len > 128`): `Err(VersionError::Invalid)`;
  no partial meta returned.
- Unknown channel token (not `stable`/`dev`/explicit `custom:` prefix):
  `Err(VersionError::UnknownChannel)`; no fallback to `stable`.
- Unsafe path segment in version (`..`, `/`, `\`, NUL): `Err(VersionError::Unsafe)`;
  `derive_paths` never called.
- Empty base dir field: `Err(VersionError::BadBaseDir)`; no path derived.
- Secret safety: version strings never logged beyond validation-failure kind;
  no env bytes read or emitted. No SQLite/OpenCode DB writes. Tests use
  disposable fixture values only, no user DB, no home-dir access.

## Resource bounds

- Input cap: raw `<= 128` bytes, each base dir `<= 1024` bytes; larger rejected
  before allocation (no unbounded retained output).
- Output cap: derived paths each `<= 2048` bytes; `Custom` channel label
  `<= 64` bytes.
- Owner/cancel path: synchronous pure functions, no threads, no detached task;
  caller owns all lifetimes; cancellation N/A (microsecond-scale compute).
- Disabled path N/A (always pure compute); zero I/O, zero global state, zero
  hidden cost.
