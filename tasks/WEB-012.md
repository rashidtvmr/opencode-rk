# WEB-012 - Plugin, app and tool chooser with approvals

Status: NOT STARTED. Kind: product. Runtime optional: False.
Mandatory for full declared release: yes.
Requirements: REQ-040.
Dependencies: native ToolRegistry, plugin/integration contracts, approvals policy.
Test obligations: WEB-012-T01, WEB-012-T02, WEB-012-T03, WEB-012-T04, WEB-012-T05.

## User-observable outcome

The composer exposes discoverable real tools/plugins/apps with enabled/disabled and
permission state. Tool calls surface approval requirements and results in the turn.

## Observable contract and tests

- **WEB-012-T01 — real capability selection:** installed/enabled native capabilities
  are discovered from the daemon, selected in the composer and included in the real
  turn/tool execution contract.
- **WEB-012-T02 — unavailable/denied:** missing adapters, disabled plugins and denied
  permissions remain unavailable/denied; the UI never routes them through another
  tool or provider as a substitute.
- **WEB-012-T03 — accessible chooser/approval:** plugin/tool search, selection and
  approval dialogs are fully keyboard reachable, disclose permissions and restore
  focus after resolution.
- **WEB-012-T04 — bounded execution:** capability lists, pending approvals and tool
  executions are bounded; cancellation/disconnect does not leave an unowned tool
  action running.
- **WEB-012-T05 — persistence/audit:** selected capabilities, tool states and approval
  decisions rehydrate from native records without exposing secrets.
