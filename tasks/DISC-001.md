## What was verified

For each repository the lock requires: commit, treeSha, origin URL, license
path, license blob SHA and license SPDX to match the on-disk checkout, plus a
detached HEAD, a clean worktree, and verified object connectivity. The lock
also requires credential-free public HTTPS GitHub URLs, valid 40-hex SHAs and
a non-empty SPDX id per entry (validated by `tools/source_lock.py`).

## Interpretation notes

- `tools/freeze_sources.py --verify` does not exist; verification is the
  `--fetch` path for already-present checkouts (tools/freeze_sources.py:82-84:
  `if path.exists(): records.append(verify_checkout(path, spec, env))`).
- The lock's `completeness` block records that the frozen manifest was
  originally prepared from API pins without a full checkout
  (`fullCheckoutObtainedHere: false`). DISC-001 closes the checkout half:
  full checkouts now exist locally and are hash-verified. The
  every-file-reviewed and feature-exhaustiveness flags remain false and are
  owned by DISC-002..010; this card does not certify parity or completeness.
