## User-observable outcome

Local-only repository cache-store lifecycle for one cache root: branch-isolated
checkout slots are inspected, locked, marked fresh/stale, and swept when stale,
entirely on the local filesystem with zero git transport, zero network, zero
credential use. Git clone/fetch/checkout/reset is explicitly NOT performed by
this slice; a `Transport` trait marks that boundary and the default guard
refuses network in tests. Operators get deterministic stale sweep with an
explicit retention policy instead of silent deletion.

## Observable contract

- `CacheSlot { cache_id: String, path: RelPath, branch: String,
  state: SlotState }` where `SlotState = Fresh | Stale { reason } |
  Missing | Corrupt { reason }` (inspection only, never repair-by-delete).
- `CacheStore::open(root: &Path, cfg: CacheCfg) -> Result<CacheStore, StoreError>`
  with `CacheCfg { max_slots: u32, max_bytes: u64, stale_after_idle: u32 }`;
  `Default` is `max_slots: 16, max_bytes: 1_073_741_824, stale_after_idle: 1`
  (monotonic tick units, no wall-clock). Any zero field =>
  `Err(InvalidCap(name))`.
- `inspect(slot) -> SlotState` (reads marker files only);
  `mark_fresh(slot, tick: u64)` (writes one bounded marker, crash-safe
  write-temp-then-rename);
  `sweep(tick: u64) -> SweepReport { removed: Vec<CacheSlot>,
  retained: Vec<CacheSlot>, freed_bytes: u64, policy: RetentionPolicy }`
  removes ONLY slots whose markers prove staleness per `RetentionPolicy`;
  `Missing`/`Corrupt` slots are reported, never swept.
- `Transport` trait (`fetch/checkout/reset`) exists as the explicit network
  boundary; this slice NEVER calls it. `NoNetworkTransport` (test default)
  panics-with-typed-error `Err(TransportRefused)` if invoked; tests assert
  the invocation counter stays zero.
- Locking: per-slot filesystem lock held during `mark_fresh`/`sweep` of that
  slot only; lock contention => `Err(SlotLocked)` with no partial marker;
  locks released on drop; no cross-process blocking wait (try-lock, fail fast).
- Deterministic: same markers + tick => identical `SweepReport` order (sorted
  by `cache_id`); tick is caller-supplied, no clock read.
- Suggested module boundary: `crates/ops/src/repo_cache_store.rs` (new crate
  `opencode-rk-ops`); fallback `crates/foundation/src/repo_cache_store.rs` if
  the workspace resists a new crate. Worker ships additive fragment only,
  never edits shared `lib.rs`, `Cargo.toml`, schemas, migrations.
- Explicit non-ownership (stays blocked): git transport (`git.ts`), clone/
  fetch/checkout/reset execution, observability sinks, installation beyond
  version metadata, `containers/**`, frozen INT-002/OPS-007/OPS-009, accepted
  BASE owners; OPS-002 parser owns normalization, this card only consumes its
  output shapes.

## Failure states

- Zero cfg field: `Err(InvalidCap(name))`; store unusable until fixed.
- Missing root: `Err(RootUnreadable)`; no partial store returned.
- Slot lock held: `Err(SlotLocked)`; no marker written, no slot removed
  (assert absence on contention, not just error string).
- Corrupt marker (unparseable, oversized): `SlotState::Corrupt` reported and
  skipped by sweep; never deleted to satisfy a byte target.
- Transport invoked: `Err(TransportRefused)` and invocation counter
  incremented (test asserts counter stays zero on every lifecycle path).
- No SQLite/OpenCode DB writes. No changes to the user's existing OpenCode
  database; tests use disposable fixture dirs only.

## Resource bounds

- Byte caps: `max_bytes` bounds summed slot sizes admitted to sweep
  accounting; marker files bounded by `MAX_MARKER_BYTES = 4 KiB` (oversized
  => `Corrupt`, never fully read); directory listing streamed, never fully
  retained (bounded work stack, cap-checked before push).
- Count caps: `max_slots` bounds tracked slots; sweep report vectors bounded
  by `max_slots`; no unbounded queue, no unbounded retained output.
- Owner/cancel path: `CacheStore::close()` releases all held locks; slot
  locks are RAII (drop releases); synchronous API, no spawned task, no
  detached guard; `sweep_cancel(store, tick, cancel: &AtomicBool)` checks the
  flag per slot and returns `Err(Cancelled)` promptly with zero removals past
  the check.
- No network, no subprocess, no global state; caller owns store lifetime and
  supplies the tick (no clock dependence in decisions).

## Test obligations (frozen)

- OPS-003-T01 (inspect/mark happy path): fixture root with 4 slots
  (2 fresh markers, 1 stale, 1 missing): `assert_eq!(inspect, Fresh)` x2,
  `Stale` x1, `Missing` x1; `mark_fresh(slot, tick)` flips stale to fresh;
  re-inspect confirms; marker file parses within `MAX_MARKER_BYTES`.
- OPS-003-T02 (sweep determinism + retention record): two `sweep` runs same
  markers+tick => `assert_eq!(report1.removed, report2.removed)` (sorted by
  `cache_id`); stale slot removed with `freed_bytes` equal to its fixture
  size; `policy` field names the explicit retention rule; fresh/missing/
  corrupt slots all retained.
- OPS-003-T03 (caps + cancel): `max_slots=2` with 4 slots =>
  only the 2 stalest swept per call, rest retained, never over cap;
  `cancel` pre-set => `assert_eq!(err, Cancelled)` with zero removals and
  return under 1s on a 1k-slot generated fixture.
- OPS-003-T04 (contention + corrupt never deleted): hold a slot lock in the
  test => `mark_fresh`/`sweep` on that slot =>
  `assert_eq!(err, SlotLocked)` with markers bit-identical before/after;
  corrupt-marker slot => `assert!(matches!(inspect, Corrupt))` and sweep
  retains it (assert still present after sweep).
- OPS-003-T05 (transport refused + safety): run T01..T04 paths against
  `NoNetworkTransport`: assert invocation counter `== 0` on every path;
  direct `transport.fetch` call => `Err(TransportRefused)`; no test writes
  outside the disposable fixture dir (assert DB/fixture-outside untouched);
  captured logs contain zero slot-body bytes beyond basenames.
