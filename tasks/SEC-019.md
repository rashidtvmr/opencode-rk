### Design
- `PolicyEffect` enum: `Allow`, `Deny`, `Audit` (Clone, Debug, PartialEq derived)
- `PolicyRule` struct: `pattern: String`, `effect: PolicyEffect`
- `ExecPolicy` struct: `rules: Vec<PolicyRule>`
- `evaluate(path_or_cmd: &str) -> PolicyEffect` - longest matching prefix wins, default Deny
- `add_rule(pattern, effect)` - adds rule to internal vector
- `remove_rule(pattern) -> bool` - removes first matching rule, returns true if removed
