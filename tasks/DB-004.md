## Observable contract

- request(conn, session, tool_call, intent_hash, policy_gen, action, mandatory, human_client, created, expires) -> pk; pending state 0
- request rejects: expires <= created, action empty or over 128 bytes, policy_generation negative, tool_call from another session
- resolve(conn, pk, to_state, human_client, resolved_us); to_state in 1, 2, 4 only (0, 3, 5 rejected)
- resolve requires pending row (missing pk, already resolved, or expired all error)
- resolve is single-winner: conditional UPDATE WHERE state = 0, changed == 0 maps to error
- mandatory_human = 1 requires Some human client identity or resolve errors
- concurrent resolve: exactly one of two racing threads succeeds, winner state 1 or 2 persisted with resolved_at_us
- terminal states 1, 2, 3, 4 immutable: resolve to 1, 2, or 4 all error, state and resolved_at_us unchanged, sweep touches nothing further
- expire_sweep(conn, now, limit): state 0 rows with expires_at_us <= now move to 3; limit clamped 1..=500; returns count
- sweep only moves due rows; expired rows reject resolve
- add_resource(conn, pk, ordinal, resource): ordinal 0..=255, resource 1..4096 bytes, FK to approvals pk
- Row decode errors map to StorageError, never panic
