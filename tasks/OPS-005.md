## User-observable outcome

Pure location-scoped config overlay computation for one workspace: merge an
ordered list of caller-supplied config documents (global < project <
`.opencode`) into one effective policy snapshot. Single evaluation, no file
discovery, no file reads, no policy-service mutation, no cache retention. Covers
only the specificity-ordering rule from the reviewed
`configuration-discovery-and-policy` partition; file discovery, policy service
writes, location-lifetime caching and the closed BASE-004/005/006/007/008
owners are explicitly out of scope.

## Observable contract

- `ConfigDoc { scope: Scope, keys: Vec<(String, String)> }`;
  `Scope = Global | Project | Local` with `Global < Project < Local`.
- `merge_overlay(docs: &[ConfigDoc]) -> Result<EffectiveConfig, OverlayError>`;
  later/higher scope wins per key; output keys sorted by key bytes.
- `EffectiveConfig { keys: Vec<(String, String)>, winner: Vec<(String, Scope)> }`.
- Deterministic: same docs bytes => identical key order and winners; no
  wall-clock, no I/O, no globals.
- Suggested module boundary: `crates/ops/src/config_overlay.rs` (additive file).
  Worker ships additive fragment only, never edits shared `lib.rs`,
  `Cargo.toml`, schemas, migrations.
- Excluded and must fail closed if attempted: filesystem discovery, file reads,
  policy-service mutation, location cache writes, BASE-006 typed-layered-config
  ownership, frozen INT-002/OPS-007/OPS-009 contracts.

## Failure states

- Empty docs slice: `Err(OverlayError::NoDocs)`; no empty config returned.
- Duplicate key inside one doc: `Err(OverlayError::DupKey)`; no partial merge.
- Empty key or key `> 256` bytes, value `> 64 KiB`: `Err(OverlayError::BadEntry)`.
- Total entries `> 4096`: `Err(OverlayError::TooMany)`; never exceed caps.
- Secret safety: values never logged (key names only on error); no DB writes.
  Tests use inline fixture docs only.

## Resource bounds

- Count cap: `<= 4096` entries total; key `<= 256` bytes, value `<= 64 KiB`;
  rejected before retention (no unbounded queue/output).
- Output cap: merged keys `<= 4096`; sorted vec only, no map retained beyond return.
- Owner/cancel path: synchronous pure function, no threads, no detached task;
  caller owns lifetimes; cancellation N/A.
- Disabled path N/A (pure compute); zero I/O, zero global state, zero hidden cost.
