## Observable contract

- Inputs: `raw: &str` reference, `branch: Option<&str>`, `cache_root: &RelPath`.
- Outputs: `NormalizedRef { canonical: String, branch: String, cache_path:
  RelPath, cache_id: String (hex, 64 chars) }`; typed `RefError`.
- `normalize_reference(raw, branch, cache_root) -> Result<NormalizedRef, RefError>`;
  default branch `main` when `None`; `cache_path =
  cache_root.join(canonical).join(branch)` shape (construction only);
  `cache_id` = hex hash of `canonical + '\0' + branch` (no network, no env).
- GitHub shorthand (`owner/repo`) accepted only with explicit `cache_root`;
  default-remote env construction excluded (caller resolves it).
- Deterministic: same inputs => identical canonical/cache_id; no wall-clock, I/O, env.
- Suggested module boundary: `crates/ops/src/repo_ref.rs` (additive file).
  Worker ships additive fragment only, never edits shared `lib.rs`,
  `Cargo.toml`, schemas, migrations.
- Excluded and must fail closed if attempted: clone/fetch/checkout/reset,
  file locks, network transport, fs mutation, user-DB writes, frozen
  INT-002/OPS-007/OPS-009 contracts.

## Failure states

- Malformed/unsupported form (empty, `> 256` bytes, not URL/shorthand):
  `Err(RefError::Invalid)`; parser returns absence, no partial ref.
- Unsafe branch (`..`, `/`, `\`, NUL, empty when explicit, `> 128` bytes):
  `Err(RefError::UnsafeBranch)`; no cache path derived.
- Empty cache root or `..` segment in root: `Err(RefError::BadCacheRoot)`.
- Secret safety: raw refs never logged beyond failure kind + basename; no
  credential/env bytes read or emitted. No DB writes. Tests use disposable
  fixture roots only.

## Resource bounds

- Input caps: raw `<= 256` bytes, branch `<= 128` bytes, cache root
  `<= 1024` bytes; larger rejected before allocation.
- Output caps: canonical `<= 256` bytes, cache path `<= 2048` bytes,
  cache_id fixed 64 hex chars.
- Owner/cancel path: synchronous pure function, no threads, no detached task;
  caller owns lifetimes; cancellation N/A.
- Disabled path N/A (pure compute); zero I/O, zero global state, zero hidden cost.
