## Observable contract

- SessionManager::new(conn) sync, Mutex<Connection>, not Clone
- create_session(title) -> SessionId via V2Writer, title limit enforced by schema
- get_session(id) -> Option<SessionRecord>, SessionRecord = SessionSummary alias
- list_sessions(limit) active only, newest first (updated_at_us DESC, pk DESC), clamped 1..=500
- list_sessions_paged(limit, offset), list_messages_paged(session, limit) extras
- rename_session / archive_session -> NotFound on missing (changed==0)
- archive sets state=1, archived_at_us, list hides archived, get still returns Archived
- append_message(session, role, content) inline only -> MessageId; missing session maps SessionNotFound to NotFound
- list_messages(session) seq ASC with message_parts ordinal=0 join; blob payloads decode to PayloadRef::blob(hex, bytes)
- session_message_count(session) -> u64
- Row decode errors map to StorageError::Sqlite(InvalidQuery), never panic
- Legacy SessionService (Storage format-1, spawn_blocking, blob put) untouched
