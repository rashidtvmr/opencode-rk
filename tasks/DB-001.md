- open(path): parent dirs created; empty/missing file initialized
  via SchemaV2; nonempty reopened via open_existing (fail-closed
  on foreign DB). Blob dir is sibling `blobs/`.
- open_memory(): same DDL/seed/markers on :memory: conn (WAL
  verification skipped, :memory: reports memory mode); BlobStore
  under temp dir. path() is None.
- Concurrency: single Mutex<Connection>; threads serialize, no
  corruption. V2Writer Immediate transactions inside.
- close(): sets workspace_state.clean_shutdown=1, WAL checkpoint.
- Happy path, failure states, and resource bounds per test obligations.
- No unbounded queue, no unbounded retained output; owner and cancel path defined.
