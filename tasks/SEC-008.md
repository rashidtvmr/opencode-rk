# SEC-008 secure process spawning

Scope: crates/security/src/spawn.rs only (plus pub mod line).

Impl: SpawnPolicy {allowed_programs, denied_programs, env_filter} with permissive/restrictive/default. SecureSpawner wraps policy: filter_env strips secret keys (API_KEY, SECRET, TOKEN, PASSWORD, PASSWD, PRIVATE_KEY, CREDENTIAL, AWS_, AUTH, ACCESS_KEY, SESSION_KEY, CLIENT_SECRET); validate_program blocks /sbin/*, /usr/sbin/* plus policy denied/allowed lists; checked_command builds env-cleared Command with filtered env. No shell strings.

Tests: env_filtered, denied_program_blocked, allowed_program_passes, system_binary_blocked, custom_policy_works.

Verify: cargo test -p opencode-rk-security && cargo check --workspace
