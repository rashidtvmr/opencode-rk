## User-observable outcome

Pure repository-reference normalization for one workspace: a reference string
plus optional branch and cache root yields a normalized reference, a typed
validation failure for invalid/unsafe input, and a branch-isolated cache path
plus stable cache identity. No clone, no fetch, no filesystem mutation, no
network, no credential read beyond the documented GitHub-default-remote
environment fallback. Deterministic parser usable without any repository
present.

## Observable contract

- `RepoRef { raw: String, branch: Option<String> }`;
  `NormalizedRef { canonical: String, branch: String, cache_path: RelPath,
  cache_id: String }`.
- `normalize_ref(raw: &str, branch: Option<&str>, cache_root: &Path)
  -> Result<NormalizedRef, RefError>` where `RefError = Empty | UnsupportedForm
  | UnsafeBranch | BranchRequired | InputTooLong`.
- Accepted forms: local path, `owner/repo` shorthand, `https://` and
  `git@` remote forms (exact accepted set frozen at RED with fixtures);
  anything else => `Err(UnsupportedForm)` with absence semantics (no partial
  `NormalizedRef` returned).
- Unsafe branches rejected deterministically: empty, path separators that
  escape the cache root (`..`, `/`, `\`), control characters, names longer
  than 255 bytes => `Err(UnsafeBranch)`. Default branch `"main"` when
  `branch` is `None` and the ref carries none.
- `cache_path` is `cache_root` joined with a sanitized
  `<host>/<owner>/<repo>/<branch>` projection that cannot escape `cache_root`
  (assert prefix containment); `cache_id` is a stable hex digest of
  (canonical, branch) - same inputs => identical id, no wall-clock, no random.
- GitHub-default-remote shorthand (`owner/repo` with no host) may consult
  exactly one environment variable for host override and nothing else; all
  other accepted forms ignore the environment entirely.
- Suggested module boundary: `crates/ops/src/repo_ref.rs` (new crate
  `opencode-rk-ops`); fallback `crates/foundation/src/repo_ref.rs` if the
  workspace resists a new crate. Worker ships additive fragment only, never
  edits shared `lib.rs`, `Cargo.toml`, schemas, migrations.
- Explicit non-ownership (stays blocked): `RepositoryCache` clone/fetch/
  checkout/reset, file locks, stale removal, background scopes (gap-file
  `repository-cache-materialization`: violates the no-network boundary);
  `git.ts` transport, `observability.ts`, `installation/**` beyond version
  metadata, `containers/**` (unresolved rule partitions); frozen
  INT-002/OPS-007/OPS-009; accepted BASE owners.

## Failure states

- Empty input: `Err(RefError::Empty)`; malformed/unsupported:
  `Err(UnsupportedForm)`; unsafe branch: `Err(UnsafeBranch)`; all with zero
  filesystem/network side effects (assert absence, not just error string).
- Input longer than `MAX_REF_BYTES = 4096`: `Err(InputTooLong)` before any
  parse allocation beyond the bound.
- `cache_path` escaping `cache_root`: construction fails closed
  (`Err(UnsafeBranch)`), never returns an escaping path.
- No SQLite/OpenCode DB writes. No changes to the user's existing OpenCode
  database; tests use in-memory strings and disposable temp dirs for path
  assertions only, never fixture checkouts.

## Resource bounds

- Byte cap: `MAX_REF_BYTES = 4096` per input; `cache_id` fixed-size digest;
  retained output bounded by one `NormalizedRef` (no unbounded queue,
  no unbounded retained output).
- No I/O (except the single documented env read for the shorthand form), no
  clock, no network, no global state, no spawned task; pure function of
  inputs. Caller owns all lifetimes.
- Cancel path: synchronous pure call, nothing to cancel; no detached task,
  no background thread.

## Test obligations (frozen)

- OPS-002-T01 (happy-path normalization): fixture matrix (local path,
  `owner/repo`, `https://`, `git@`, each with explicit branch and with
  default): `assert_eq!(out.canonical, expected)` per row,
  `assert_eq!(out.branch, "main")` for defaults,
  `assert!(out.cache_path.starts_with(cache_root))`.
- OPS-002-T02 (determinism + cache identity): two `normalize_ref` calls same
  inputs => `assert_eq!(a, b)` (path AND id); different branches =>
  `assert_ne!(a.cache_id, b.cache_id)` and `assert_ne!(a.cache_path,
  b.cache_path)`; ids sorted/stable across process restarts (frozen vector).
- OPS-002-T03 (unsafe rejection): table of unsafe branches (`""`, `"../x"`,
  `"a/b"`, control chars, 300-byte name): each =>
  `assert_eq!(err, UnsafeBranch)`; escaping branch never yields a path
  outside `cache_root` (assert prefix containment on every row).
- OPS-002-T04 (unsupported + overlong): malformed rows (`""`, `"::::"`,
  `"ftp://..."`, protocol-relative) => `Err(Empty|UnsupportedForm)` with no
  partial value; 8 KiB input => `assert_eq!(err, InputTooLong)`; env-override
  var set vs unset changes ONLY the `owner/repo` shorthand host, never other
  forms (assert byte-identical outputs for non-shorthand rows in both envs).
- OPS-002-T05 (absence of side effects + safety): run full matrix with a
  read-only fake root and network-blocked fixture: assert zero files created
  (pre/post dir listing identical), zero DB writes (assert DB/fixture-outside
  untouched), captured logs contain zero reference-body bytes beyond the
  input basename.
