## Enterprise-remote heterogeneity boundary (binding)

The pinned `packages/enterprise/**` + `packages/function/**` surface is
heterogeneous, not one contract. Exactly one narrow pure sub-partition is
owned here; every other partition is explicitly refused:

- OWNED: deterministic validation + last-write-wins merge of a
  caller-supplied share descriptor (pure, secret-by-reference only).
- REFUSED (not owned, not implemented, must fail closed as
  `HostedPartition` when attempted through this API):
  1. `enterprise-share-http` transport: HTTP routes, legacy `/api/share`
     vs org `/api/shares` semantics, network sync/retry, durable
     metadata/secret lifetime, deletion guarantees.
  2. `function-syncserver-websocket-r2`: SyncServer fanout, WebSocket
     state, R2/object-store persistence, cassette/queue backpressure.
  3. `function-support-relay`: support-message relay, admin behavior.
  4. `function-github-token-exchange-installation`: GitHub OIDC/PAT
     exchange, installation lookup, any OAuth/token issuance.
  5. `deployment-resource-lifecycle`: Cloudflare Durable Objects/R2,
     Discord/GitHub network calls, SST deployment, cert/MITM/proxy
     lifecycle.
- Secret rule: this slice holds opaque `key_ref` strings only (1..=64
  chars, never raw secret bytes); empty key_ref => `Err(ShareError::Secret
  Invalid)` with no share state mutated. No credential storage, no token
  minting, no env reads.
- Cross-ids: `SHARE-003` and `WEB-004` remain separate owners; this card
  assigns none of their transport/persistence/auth behavior. Accepted
  `PROV-006` ownership stays closed and untouched.

## Observable contract

- `ShareDesc { id: String, key_ref: String, digest: String, seq: u64 }`:
  `id` 1..=64 chars `[A-Za-z0-9][A-Za-z0-9._-]*`; `key_ref` 1..=64 chars
  same charset (opaque reference, never secret bytes); `digest` exactly 64
  hex chars (caller-computed payload digest); `seq` monotonic per `id`.
- `ShareView { id, key_ref, digest, seq }` (last-write-wins projection);
  `SyncOp { Upsert(ShareDesc), Remove { id, seq }, ProbeHosted(HostedKind) }`;
  `HostedKind { ShareHttp, SyncWsR2, SupportRelay, GithubExchange, Deploy }`.
- `ShareSync::new() -> ShareSync` (empty, no I/O, no threads).
  - `apply(op: SyncOp) -> Result<Option<ShareView>, ShareError>`: validates
    shapes; `Upsert` with `seq > stored.seq` replaces and returns the new
    view; `seq <= stored.seq` keeps stored view (returns stored clone, no
    mutation); `Remove` with `seq > stored.seq` deletes (returns `None`);
    stale `Remove` keeps stored. Unknown id `Remove` => `Ok(None)`,
    store unchanged.
  - `get(id) -> Option<ShareView>`; `list() -> Vec<ShareView>` sorted by
    `id` ascending (deterministic).
  - `ProbeHosted(kind)` always => `Err(ShareError::HostedPartition)` for
    every `HostedKind`; proves the boundary: hosted partitions are
    refused by type, never executed.
- `ShareError { InvalidId, SecretInvalid, InvalidDigest, Overflow, HostedPartition }`.
- Bounds as explicit public constants (upstream supplies none; frozen RED
  owns values): `MAX_SHARES: usize = 256`, `MAX_ID_LEN = 64`,
  `MAX_KEYREF_LEN = 64`.
- Deterministic: same `apply` sequence => identical `list()`; no
  wall-clock; `seq` is caller-supplied (no clock read).
- Suggested module boundary: new pure in-memory module
  `crates/integration/src/share_sync.rs` (same crate as INT-007/009);
  worker ships additive fragment only, never edits shared `lib.rs`,
  `Cargo.toml`, schemas, migrations. Independent test owner:
  `crates/integration/tests/share_sync.rs` (or equivalent).
- Explicitly excluded: network/HTTP routes, WebSocket/Durable Objects,
  R2/object store, GitHub OIDC/PAT, support relay, SST/deployment,
  credential/secret storage, env reads, DB persistence, legacy migration,
  EventV2 subscription, background work, new dependencies.

## Failure states

- Invalid id (empty, too long, bad charset): `Err(InvalidId)`; store unchanged.
- Empty/oversize `key_ref`: `Err(SecretInvalid)`; store unchanged; no
  secret bytes ever accepted (only opaque refs).
- Malformed digest (not exactly 64 hex chars): `Err(InvalidDigest)`;
  store unchanged.
- Stale `seq` (`<= stored.seq`) for upsert/remove: no mutation; returns
  stored view (`Upsert`) or stored view kept (`Remove`); never last-write-loses.
- Any `ProbeHosted(kind)`: `Err(HostedPartition)` for all five kinds;
  store unchanged; proves hosted refusal.
- `Remove` unknown id: `Ok(None)`; store unchanged (harmless).
- Secret safety: descs hold id/key_ref/digest only; no payload bodies, no
  tokens; nothing secret logged. No SQLite/OpenCode DB writes. Tests use
  disposable in-memory sync only.

## Resource bounds

- Count cap: `MAX_SHARES` bounds the map; `apply` cap-checks before
  insert of a new id (updates to existing ids need no new slot); overflow
  new-id insert => `Err(ShareError::Overflow)`; never exceeds cap.
- Byte caps: id/key_ref/digest length rules bound retained bytes (max
  ~256 * ~200 bytes, small and constant); `list()` returns a bounded vec
  copy; no unbounded retained output.
- Owner/cancel path: caller owns the `ShareSync` lifetime and all `seq`
  values; all methods synchronous on `&mut self`/`&self`, spawn no
  thread; no cancellation token needed (sub-microsecond ops); no detached
  task, no background finalizer, no host process.
- Zero hidden cost: `new()` allocates only the empty map; `ProbeHosted`
  allocates nothing.
