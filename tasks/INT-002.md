## User-observable outcome

Caller-driven key/OAuth connection API projection for one caller-owned
connection table at a time: callers connect a registered integration by key
descriptor or drive an OAuth attempt to completion with caller-supplied
code material, query connection state, and disconnect by id. This slice
resolves connections to `active` / `code-required` / `not-found` typed
outcomes only; it performs no network I/O, executes no provider
authorize/refresh callback, persists nothing, and publishes no events. The
caller owns code material lifetime, actual OAuth transport, secret storage,
and event publication.

## Observable contract

- `ConnectInput { integration: String, method_id: String, code: Option<String> }`:
  `integration`/`method_id` same charset as INT-001
  (`[A-Za-z0-9][A-Za-z0-9._-]*`, 1..=64 chars); `code`, when present,
  1..=512 chars printable ASCII. Code material is borrowed (`&str`), never
  retained.
- `ConnectionState { Active, CodeRequired }`; `ConnectionInfo { id:
  ConnId(u64), integration: String, method_id: String, state:
  ConnectionState }`. No secret/code/token field exists on any returned
  type (type-level guarantee).
- `ConnectionTable::new() -> ConnectionTable` (empty, no I/O, no threads).
  - `connect(&mut self, input: &ConnectInput, known: &KnownMethods) ->
    Result<ConnectionInfo, ConnectError>`: `known` is a caller-supplied
    `&dyn Fn(&str, &str) -> Option<MethodKind>` answering whether
    (integration, method) names a registered key/OAuth method. Unknown
    pair => `Err(ConnectError::NotFound)`; OAuth method with `code: None`
    => `Err(ConnectError::CodeRequired)` with nothing recorded; key method
    or OAuth with code => records `Active` with monotonic `ConnId` from 1
    and returns its `ConnectionInfo` clone. Code bytes are consumed for the
    verdict only, never stored.
  - `get(&self, id: ConnId) -> Option<&ConnectionInfo>`.
  - `list(&self) -> Vec<&ConnectionInfo>` sorted by `ConnId` ascending.
  - `disconnect(&mut self, id: ConnId) -> bool`: removes only that id;
    unknown id => `false`, table otherwise unchanged.
- `ConnectError { NotFound, CodeRequired, InvalidInput, Overflow }`:
  `InvalidInput` for empty/bad-charset/oversize fields; `Overflow` when
  `len == MAX_CONNECTIONS`. Auth normalization: no provider reason leaks;
  unknown vs disallowed are both `NotFound` (mirrors the handler's
  normalized failures).
- Bounds as explicit public constants (upstream supplies none; frozen RED
  owns values): `MAX_CONNECTIONS: usize = 64`, `MAX_CODE_LEN = 512`.
- Deterministic: same input sequence + same `known` answers => identical
  ids and `list()`. No wall-clock, no provider clock.
- Suggested module boundary: new pure in-memory module
  `crates/providers/src/connection.rs` (crate `opencode-rk-providers`);
  worker ships additive fragment only, never edits shared `lib.rs`,
  `Cargo.toml`, schemas, migrations. Independent test owner:
  `crates/providers/tests/integration_connection.rs`.
- Explicitly excluded: scoped registry internals (INT-001), attempt
  pending/complete/expired/cancel lifecycle (INT-004), plugin bridging
  (EXT-007), provider authorize/refresh/callback execution, refresh
  scheduling, env-variable resolution, secret/token persistence, network,
  HTTP routes, events, background scrubber, PTY/project/location/
  client-server behavior, new dependencies.

## Failure states

- Unknown (integration, method) pair: `Err(ConnectError::NotFound)`;
  table unchanged; no reason string distinguishes unknown from disallowed.
- OAuth method without code: `Err(ConnectError::CodeRequired)`; table
  unchanged; no partial connection recorded.
- Invalid input (empty/bad-charset name/method, oversize code):
  `Err(ConnectError::InvalidInput)`; table unchanged.
- Table full (`len == MAX_CONNECTIONS`): `Err(ConnectError::Overflow)`;
  table unchanged; never exceeds cap.
- `disconnect` unknown id: returns `false`; table unchanged (harmless).
- Secret safety: `code` is `&str`-borrowed for the call and dropped on
  return; `ConnectionInfo` contains no code/secret/token field by
  construction; debug/log impls (if any) redact to variant names only. No
  SQLite/OpenCode DB writes. Tests use disposable in-memory tables and
  short fixture codes only.

## Resource bounds

- Count cap: `MAX_CONNECTIONS` bounds the vec; `connect` cap-checks before
  insert; no unbounded queue of pending connections.
- Byte caps: name/method/code length caps bound per-call bytes (max ~640
  bytes input); retained `ConnectionInfo` bounded by name/method caps only
  (code never retained); no unbounded retained output.
- Owner/cancel path: caller owns the table, the `known` oracle, and all
  input/code lifetimes; `connect`/`disconnect` synchronous on
  `&mut self`, spawn no thread; no cancellation token needed
  (sub-microsecond ops); no detached task, no background callback, no
  network handle.
- Zero hidden cost: `new()` + `list()` allocates only the empty vec; idle
  cost is the caller-owned table only.

## Test obligations (frozen)

- INT-002-T01 (happy path): `known` oracle maps `("gh","key") => Key`,
  `("gh","oauth") => OAuth`; `connect` key with no code => `Ok`, id 1,
  `state == Active`; `connect` oauth with `Some("code-1")` => `Ok`, id 2;
  `get(1).method_id == "key"`; `list()` ids `[1,2]` in order.
- INT-002-T02 (code-required): `connect` oauth with `code: None` =>
  `assert_eq!(err, CodeRequired)`; table len unchanged (still 1 after a
  prior key connect); `connect` unknown pair `("nope","key")` =>
  `assert_eq!(err, NotFound)`; a disallowed-but-wellformed pair also =>
  `NotFound` (normalization: both arms identical variant).
- INT-002-T03 (validation + overflow, table unchanged): empty integration
  => `Err(InvalidInput)`; bad-charset method (`"a/b"`) =>
  `Err(InvalidInput)`; 513-char code => `Err(InvalidInput)`; fill to
  `MAX_CONNECTIONS` then one more => `Err(Overflow)` and `list().len() ==
  MAX_CONNECTIONS`; each error leaves `list()` byte-identical to before.
- INT-002-T04 (disconnect + no retention): `disconnect(1)` => `true`,
  `get(1)` is `None`, `list()` holds only id 2; `disconnect(1)` again =>
  `false`, `list()` unchanged; after an oauth-with-code connect, assert
  the returned `ConnectionInfo` has no code field (compile-time: field
  access fails) and a memory scan of the table debug output contains zero
  bytes of the input code.
- INT-002-T05 (no network/secret side-effect safety): run full matrix
  while asserting no child process spawned, no network handle opened, no
  files outside the disposable test dir, no DB writes; captured logs
  contain zero code bytes and zero credential-like bytes; `known` oracle
  call count equals exactly the number of `connect` calls (no hidden
  retries/callbacks).
