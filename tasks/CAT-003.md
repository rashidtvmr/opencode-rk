# CAT-003: Catalog Health Checks for Plugins

## Goal
Catalog health checks for plugins.

## Scope
- Implement health check tracking in `crates/catalog/src/health.rs`.
- Define `HealthStatus` enum, `PluginHealth` struct, `HealthChecker` tracker.

## Design

### `HealthStatus` enum
- `Healthy`
- `Degraded(String)` - reason string
- `Unhealthy(String)` - reason string

### `PluginHealth` struct
- `plugin_id: String`
- `status: HealthStatus`
- `last_check: SystemTime`
- `response_ms: u64`

### `HealthChecker`
- `new(max_history: usize)` - creates checker with bounded history.
- `record(plugin_id, status, response_ms)` - records a check; evicts oldest when at capacity.
- `check(plugin_id) -> Option<&PluginHealth>` - returns the latest record for a plugin.
- `is_healthy(&self) -> bool` - true if all records are `Healthy`.
- `get_all() -> Vec<&PluginHealth>` - all records.
- `prune_old(now, max_age_secs) -> usize` - removes entries older than age; returns count removed.
