## Summary

`ManualOnlyPolicy` classifies commands as auto-executable vs manual-only.
Agent presents manual-only command to user via `ManualInstruction`, never executes directly.

## API

- `is_manual_only(program, args) -> bool`
- `ManualOnlyPolicy::is_manual_only` + `present_to_user(program, args) -> ManualInstruction`
- `ManualInstruction { command: String, warning: String }`

## Manual-only set

- `rm -r`/`-R` with system paths (/ /etc /usr /bin /sbin /boot /dev /proc /sys, C:/Windows); plain `rm file` stays auto
- `mkfs*`, `format`, `fdisk`, `sfdisk`, `parted`, `iptables`/`ip6tables`, `reboot`, `shutdown`, `halt`, `poweroff`, `useradd`, `userdel`, `adduser`, `deluser`, `passwd`, `chpasswd`
- `systemctl stop/disable/halt/poweroff/reboot` only; `start`/`status` stay auto
