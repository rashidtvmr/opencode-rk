# WEB-010 - Structured WYSIWYG chat composer

Status: IN PROGRESS / NOT ACCEPTED. Kind: product. Runtime optional: False.
Mandatory for full declared release: yes.
Requirements: REQ-040.
Dependencies: existing model/effort controls; session input/turn submission state.
Test obligations: WEB-010-T01, WEB-010-T02, WEB-010-T03, WEB-010-T04, WEB-010-T05.

## User-observable outcome

The composer is an accessible WYSIWYG structured editor with model/effort controls,
slash commands, mentions, attachment/tool/plugin affordances, draft preservation and
real send/stop/queue/steer behavior.

## Observable contract and tests

- **WEB-010-T01 — structured edit/send:** rich multiline text/code editing, model and
  effort selection lower deterministically to the native request contract.
- **WEB-010-T02 — paste/format failure:** arbitrary HTML and unsupported document
  nodes are sanitized/lowered safely; unsupported capability chips cannot be sent as
  if they were active.
- **WEB-010-T03 — editor accessibility:** keyboard users can edit, undo/redo, open
  menus, insert newline and send without focus traps; labels/roles are screen-reader
  usable and shortcut help is discoverable.
- **WEB-010-T04 — bounds/cancel/queue:** document/draft/queue sizes are bounded; stop
  aborts the live turn; queued/steered drafts retain deterministic ownership.
- **WEB-010-T05 — draft/reload compatibility:** draft state and supported document
  structure recover as specified, while older plain-text messages remain editable as
  a compatible document.

## Current implementation boundary

- The browser editor now uses explicit paragraph/code blocks, sanitizes paste to
  clipboard plain text and lowers deterministically to the native `text` request.
- Drafts are retained per chat in browser-local storage with the same 32 KiB bound
  as the native TUI composer state. Model and reasoning effort remain the real native
  request fields.
- Stop aborts the browser-owned live stream, which releases the existing native turn
  stream/permit path on disconnect.
- Slash commands, mentions and queue/steer remain disabled because the HTTP turn
  boundary does not expose those native contracts yet. File/tool/plugin/voice chips
  likewise stay unavailable and cannot be submitted as active capabilities.
- Browser acceptance remains blocked while the policy-compliant worktree lacks
  runnable `vitest`/`tsc`; do not mark this task accepted from static inspection.
