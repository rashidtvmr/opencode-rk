## User-observable outcome

A caller embedding the agent over stdio observes ACP v1 JSON-lines framing: one JSON object per line for initialize, session new/load/prompt, modes/models/variants queries; every inbound frame under 1 MiB decodes to a typed request and every outbound response encodes as a single line; malformed or oversize frames are rejected with a typed protocol error and leave session state untouched. No real terminal, no auth, no full history restore (explicit upstream non-goals, preserved).

## Observable contract

- `AcpRequest { Initialize, SessionNew, SessionLoad { session_id }, SessionPrompt { session_id, text }, GetModes, GetModels, GetVariants }`: text 1..=65_536 chars; session_id 1..=128 chars.
- `AcpResponse { Ok { body: String }, Error { code: AcpErrorCode } }`: body max 1 MiB; exactly one JSON object per encoded line, trailing `\n`.
- `decode_frame(line: &[u8]) -> Result<AcpRequest, AcpError>`: rejects > MAX_ACP_FRAME_BYTES, non-UTF8, multi-object lines, unknown methods.
- `encode_frame(response: &AcpResponse) -> Result<Vec<u8>, AcpError>`: single line plus `\n`; oversize body => `Err(TooLarge)`, nothing emitted.
- `AcpSession { id: String, mode: String }`: `session_new()` mints a caller-visible id; `session_load(id)` resolves or errors; `session_prompt(id, text)` records the prompt against that session only.
- Bounds as explicit public constant: `MAX_ACP_FRAME_BYTES: usize = 1_048_576` (1 MiB) both directions.
- Deterministic: same input lines => byte-identical output lines; no wall-clock, no I/O inside codec, no globals.
- Suggested module boundary: `crates/server/src/acp_bridge.rs` owning AcpRequest, AcpResponse, AcpSession, AcpError, AcpErrorCode, MAX_ACP_FRAME_BYTES, decode_frame, encode_frame, session_new/load/prompt; shared lib.rs wiring left to integrator.
- Explicitly excluded: file read/write (ACP-002), capability negotiation beyond modes/models/variants listing, complete update streaming, tool-call reporting, mode switching, auth, real terminal, full history restoration, actual stdio transport (caller owns FDs; this module is a pure codec plus in-memory session map).

## State and persistence transitions

- Codec: stateless; decode/encode perform no state change by construction.
- Session map: absent -> present (session_new) -> prompted (session_prompt appends to that session's prompt list); session_load is read-only.
- Unknown session on load/prompt: `Err(UnknownSession)`; map unchanged; no session created as a side effect.
- Persistence: none in this slice; the map is caller-owned memory. History restore beyond the in-memory prompt list is an explicit non-goal.

## Failure states

- Oversize frame (> 1 MiB): `Err(AcpError::TooLarge)`; nothing decoded, map unchanged, nothing emitted.
- Non-UTF8 bytes: `Err(AcpError::InvalidUtf8)`; map unchanged.
- Malformed JSON or unknown method: `Err(AcpError::BadFrame)` / `Err(AcpError::UnknownMethod)`; map unchanged.
- Unknown session id on load/prompt: `Err(AcpError::UnknownSession)`; map unchanged.
- Empty prompt text or oversize text: `Err(AcpError::InvalidInput)`; session prompt list unchanged.
- Oversize response body on encode: `Err(AcpError::TooLarge)`; no partial line emitted (asserted by emitted-bytes test).
- Secret safety: frames carry caller bytes only; errors carry codes, never frame content. Tests use fixture frames; no network, no DB writes.

## Resource bounds

- Frame cap: MAX_ACP_FRAME_BYTES bounds every decode and encode; rejected before retention (no unbounded queue/output).
- Session map: caller-owned; module documents a recommended cap of 64 sessions but enforces no hidden eviction (caller caps; exceeding callers get `Err(TooManySessions)` past 64).
- Owner/cancel path: caller owns the map and all FDs; codec functions synchronous, spawn no thread; no cancellation token needed; no detached task, no background reader, no network handle.
- Zero hidden cost: codec allocates only the decoded/encoded value; idle cost is zero (no statics).
