## Observable contract

- `InfoSnapshot { cwd_label, workspace, session_label, provider_id, model, auth_mode, ctx_window, ctx_used, tokens_in, tokens_out, cost_micros: Option<u64>, mcp_connected, mcp_enabled, mcp_disabled, active_tools: BoundedVec<String>, queue_depth, status_line, updated_ms, warnings: BoundedVec<String> }`: all caller-supplied, no secrets by type.
- `render(snapshot, width) -> Vec<String>`: pure renderer; full layout at width >= 100, compact single-column at width < 60; every line within width; secrets never emitted (no token-like substrings by construction).
- `summarize(snapshot) -> PanelCounts { tools_shown, warnings_shown, truncated: bool }`: reports truncation honestly.
- Bounds: active tools max 16, warnings max 8, each label max 128 chars, cwd label max 256 chars; over-cap truncates with "+N more" marker.
- Context math saturating: remaining = window saturating_sub used; never underflows, never panics.
- Deterministic: same snapshot plus width yields byte-identical lines; no I/O, no clock reads (caller supplies updated_ms).
- Suggested module boundary: crates/sessions/src/tui_info_panel.rs owning InfoSnapshot, PanelCounts, InfoError, render, summarize; shared lib.rs wiring left to integrator.

## Failure states

- Empty title/workspace/session label: `Err(InfoError::EmptyField)`; nothing rendered.
- Width below 20 columns: `Err(InfoError::TooNarrow)`; caller falls back to status line only.
- Over-cap tools/warnings: truncate with marker, truncated true; never exceed caps.
- Counter overflow: saturating math, never wraps, never panics.
- Secret safety: renderer accepts labels and counts only; token values unrepresentable; tests scan output for secret patterns and fail closed. No DB writes; disposable snapshots only.

## Resource bounds

- Pure renderer: no Command, no thread, no I/O, no network; output bounded by line caps times width.
- O(fields) time, O(lines) memory; no retained state between calls.
- No unbounded queue, no unbounded retained output; owner and cancel path defined per crates/sessions/src/ui_006.rs:13-41 panel precedent.
