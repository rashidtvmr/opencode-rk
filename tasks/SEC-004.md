# SEC-004 - Sensitive file and env protection

Status: DONE. Kind: product. Runtime optional: False.
Requirements: REQ-027.
Owned file: crates/security/src/sensitive.rs (replaced stub).
Contracts: no shared contract edits. lib.rs already declares pub mod sensitive.

## Outcome

SensitivePathChecker with default glob patterns blocks dotenv, ssh, aws,
gcloud, gnupg, key files, netrc, npmrc, docker/kube configs, git-credentials,
token/credentials paths. EnvFilter removes KEY/SECRET/TOKEN/PASSWORD/CREDENTIAL
suffixed vars plus AWS_*, OPENAI_*, ANTHROPIC_*, GITHUB_TOKEN, DATABASE_URL.
Both configurable via add/remove. filter returns only safe vars.

## Contract

- SensitivePathChecker::new/default patterns listed above.
- is_sensitive(path) case-insensitive, matches full normalized path or basename,
  glob * = any chars incl /. Substring fallback for patterns without *.
- add_pattern/remove_pattern(bool removed).
- EnvFilter::new default denies listed above, matched uppercase name.
- is_denied(name), denies(), filter(&map)->map of safe only.
- add_deny/remove_deny(bool removed).
- Simple glob matcher local to module, no regex dep.
