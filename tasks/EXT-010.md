## User-observable outcome

An explicit deferred-activation boundary for configured external plugin
discovery: while external JS/TS plugin loading remains design work upstream,
the native side exposes a bounded, auditable record of configured
package/file discovery intents that performs zero filesystem traversal,
zero npm resolution/install, zero dynamic import, and activates zero
external code. A discovery intent is validated, recorded as
`Deferred(ExternalDiscoveryDeferred)`, and reported back; a
`list_deferred()` projection shows exactly what is still pending and why.
Package install/update network policy, cache policy, and module
validation/failure policy stay deferred and are not invented here.

## Observable contract

- `DiscoveryRef { package: Option<String>, file: Option<String> }`: exactly
  one of `package`/`file` must be `Some`; `package` 1..=128 chars npm-shape
  `[A-Za-z0-9][A-Za-z0-9._@/-]*`; `file` 1..=256 chars relative-path shape
  `[A-Za-z0-9][A-Za-z0-9._/-]*` (no leading `/`, no `..` segment).
- `DeferredReason { ExternalDiscoveryDeferred }`.
  `DiscoveryEvent { seq: u64, scope: u64, reference: DiscoveryRef,
  reason: DeferredReason }`.
- `EXT10_MAX_DEFERRED: usize = 128` (explicit public constant; upstream
  supplies none; frozen RED owns value).
- `DiscoveryBoundary::new() -> DiscoveryBoundary` (empty, no I/O, no threads).
  - `declare(scope: u64, reference: DiscoveryRef) -> Result<u64, DiscoveryError>`:
    validates shape (exactly-one-set, charset, traversal rejection),
    records `ExternalDiscoveryDeferred`, returns `seq` from 1. Never touches
    any registry, filesystem, network, or host.
  - `revoke_scope(scope: u64) -> u64`: removes only that scope's events,
    returns count removed; unknown scope => 0, log otherwise unchanged.
  - `list_deferred() -> Vec<DiscoveryEvent>` sorted by `seq` ascending.
  - `drain(n: usize) -> Vec<DiscoveryEvent>`: removes and returns oldest `n`
    (or fewer); explicit shrink path.
- Deterministic: same declare/revoke sequence => identical `seq` series and
  identical `list_deferred()`. No wall-clock anywhere.
- Suggested module boundary: `crates/ext/src/external_discovery.rs` (same new
  crate `opencode-rk-ext` as EXT-001/002/004); worker ships additive fragment
  only, never edits shared `lib.rs`, `Cargo.toml`, schemas, migrations.
  Independent test owner:
  `crates/ext/tests/plugin_external_discovery.rs`.
- Runtime optional True: when the boundary feature is off, none of these
  functions is called; the log is never constructed; zero cost (mirrors
  TOOL-016 opt-out proof).
- Explicitly excluded: filesystem glob/traversal, npm resolution/install,
  dynamic JS import, executable plugin callbacks, host launch/subprocess,
  hook execution (REQ-020), skill/command discovery, UI presentation
  (REQ-005), file extraction (EXT-013), policy gating (TOOL-007), network,
  persistence, environment lookup, credentials/secrets, HTTP routes,
  background work, new dependencies. A declaration must never mutate plugin
  readiness or execute anything.

## Failure states

- Both/neither set (`package`+`file` both `Some` or both `None`):
  `Err(DiscoveryError::InvalidRef)`; log unchanged.
- Bad package/file shape (empty, too long, bad charset, absolute path,
  `..` segment): `Err(DiscoveryError::InvalidRef)`; log unchanged.
- Over deferred cap (`len == EXT10_MAX_DEFERRED`): `declare` returns
  `Err(Overflow)`; log unchanged; never exceeds cap.
- `revoke_scope` unknown scope: returns `0`; unchanged (harmless).
- `drain(0)`: returns empty vec, log unchanged. `drain(n > len)`: returns
  all events, log empty; never panics.
- Secret safety: events hold seq/scope/ref-shape only; no file bodies, no
  credentials; nothing secret logged. No SQLite/OpenCode DB writes. Tests use
  disposable in-memory logs only.

## Resource bounds

- Count cap: `EXT10_MAX_DEFERRED` bounds the event vec (push cap-checked;
  overflow errors instead of growing); `drain` gives the owner an explicit
  shrink path; no unbounded queue.
- Byte caps: package/file length caps bound retained bytes (max ~128 * 384
  bytes, small and constant); events are small fixed-shape structs; no
  unbounded retained output.
- Owner/cancel path: caller owns the `DiscoveryBoundary` lifetime and scope
  ids; all methods synchronous, non-blocking, constant-time; no cancel flag
  needed (nothing blocks); no detached task, no background thread, no OS
  handle, no host process.
- Disabled path (feature off): log never constructed; zero allocation, zero
  threads, zero file handles, zero I/O.

  `Err(InvalidRef)`; absolute file `"/x/y.js"` and traversal
  `"a/../b.js"` => `Err(InvalidRef)`; 129-char package => `Err(InvalidRef)`;
  fill to `EXT10_MAX_DEFERRED` => next `declare` is `Err(Overflow)` and len
  stays capped; `drain(10)` returns oldest 10 (seqs 1..=10);
  `drain(usize::MAX)` empties; each error leaves `list_deferred()`
  byte-identical to before the call.

  `list()` byte-identical afterwards; assert no dynamic import/host call
