## User-observable outcome

Deferred external activation boundary for plugin hook contributions: native
code can record which plugin scope contributed which bounded before/after
tool-hook declaration, replay those declarations in registration order, and
prove that no external JS/TS module is imported, no hook handler executes,
and no tool input/output is mutated by this slice. Real handler execution
and input/output mutation stay deferred behind an explicit activation gate
that is closed by default. Permission checks (SEC-001), the hook bus itself
(SEC-010/SEC-011/SEC-020), and tool internals are explicitly out of scope.

## Observable contract

- `HookPhase { Before, After }`; `HookDecl { phase: HookPhase, tool_filter:
  String, label: String }`: `tool_filter` 1..=64 chars glob charset
  `[A-Za-z0-9*._-]`; `label` 1..=64 chars `[A-Za-z0-9][A-Za-z0-9._-]*`.
- `ActivationGate { closed }`: `closed()` default; `open()` requires explicit
  caller call (tests open it only to assert the boundary still holds; opening
  never imports or runs anything in this slice).
- `HookBoundary::new() -> HookBoundary` (empty, no I/O, no threads).
  - `declare(scope: u64, decl: HookDecl) -> Result<u64, HookError>`:
    validates filter/label, rejects duplicates (same scope+phase+filter+label)
    and overflow, assigns monotonic `HookId(u64)` from 1, records insertion
    order. Works identically whether the gate is open or closed (recording is
    not execution).
  - `revoke_scope(scope: u64) -> u64`: removes only that scope's decls,
    returns count removed; unknown scope => 0, registry otherwise unchanged
    (mirrors EXT-003 close-unknown semantics).
  - `list() -> Vec<(HookId, u64 /*scope*/, HookDecl)>` sorted by `HookId`
    ascending (registration order, deterministic).
  - `replay() -> Vec<HookDecl>` in registration order (pure projection for
    the future executor; performs zero calls).
  - `try_execute(id) -> Err(HookError::Deferred)`: always deferred while the
    gate is closed AND while open in this slice (no executor ships here);
    proves the boundary: recording/replay never runs a handler.
- Bounds as explicit public constants (upstream supplies none; frozen RED
  owns values): `MAX_HOOK_DECLS: usize = 128`, `MAX_FILTER_LEN = 64`,
  `MAX_LABEL_LEN = 64`.
- Deterministic: same declare/revoke sequence => identical `list()`/`replay()`.
  No wall-clock in ordering or ids.
- Suggested module boundary: new pure in-memory module
  `crates/ext/src/hook_boundary.rs` (crate `opencode-rk-ext`); worker ships
  additive fragment only, never edits shared `lib.rs`, `Cargo.toml`, schemas,
  migrations. Independent test owner:
  `crates/ext/tests/plugin_hook_boundary.rs`.
- Explicitly excluded: handler execution, input/output mutation, failure
  semantics for mutation, permission evaluation (SEC-001), hook bus dispatch
  (SEC-010/SEC-011/SEC-020), tool internals, external JS/TS import, dynamic
  registration into a live bus, reload/watch, filesystem, network,
  persistence, environment lookup, credentials/secrets, HTTP routes,
  background work, new dependencies.

## Failure states

- Invalid filter (empty, too long, bad charset):
  `Err(HookError::InvalidFilter)`; registry unchanged.
- Invalid label (empty, too long, bad charset):
  `Err(HookError::InvalidLabel)`; registry unchanged.
- Duplicate (same scope+phase+filter+label):
  `Err(HookError::Duplicate)`; registry unchanged, no id consumed.
- Registry full (`len == MAX_HOOK_DECLS`): `Err(HookError::Overflow)`;
  registry unchanged; never exceeds cap.
- `try_execute` any id (known or unknown): `Err(HookError::Deferred)`; no
  handler runs, no input/output touched, gate state unchanged. Unknown id
  additionally observable as deferred (not executed), never as success.
- `revoke_scope` unknown scope: returns `0`; registry unchanged (harmless).
- Secret safety: decls hold filter/label strings only; no tool I/O, no
  credentials; nothing secret logged. No SQLite/OpenCode DB writes. Tests use
  disposable in-memory boundary only.

## Resource bounds

- Count cap: `MAX_HOOK_DECLS` bounds the vec; `declare` cap-checks before
  push; no unbounded queue of pending declarations.
- Byte caps: filter/label length caps bound retained bytes (max ~128 * 128
  bytes, small and constant); `replay()` returns a bounded vec copy; no
  unbounded retained output.
- Owner/cancel path: caller owns the `HookBoundary` lifetime and scope ids;
  all methods synchronous on `&mut self`/`&self`, spawn no thread; no
  cancellation token needed (sub-microsecond ops); no detached task, no
  background finalizer, no host process.
- Zero hidden cost: `new()` + `list()` allocates only the empty vec; opening
  the gate allocates nothing and starts nothing.

## Test obligations (frozen)

- EXT-008-T01 (happy path): gate closed; declare 3 decls across 2 scopes
  (before+after mix) => ids 1,2,3; `list().len() == 3` in id order;
  `replay()` returns the 3 decls in the same order; `list()` phases/filters
  match inputs.
- EXT-008-T02 (scope revoke): declare 2 in scope 7, 1 in scope 8;
  `revoke_scope(7)` => 2 and `list().len() == 1` with scope-8 decl only;
  `revoke_scope(unknown)` => 0 and `list()` unchanged; re-declare same
  filter/label under a fresh scope after revoke => `Ok` (no ghost duplicate).
- EXT-008-T03 (validation, registry unchanged): duplicate decl =>
  `Err(Duplicate)`; empty/bad filter => `Err(InvalidFilter)`; empty/bad
  label => `Err(InvalidLabel)`; fill to `MAX_HOOK_DECLS` then one more =>
  `Err(Overflow)` and `len == MAX_HOOK_DECLS`; each error leaves `list()`
  byte-identical to before the call.
- EXT-008-T04 (deferred execution): gate closed: `try_execute(known)` =>
  `assert_eq!(err, Deferred)`; `try_execute(unknown)` => `Err(Deferred)`;
  open the gate: `try_execute(known)` still => `Err(Deferred)`; sentinel
  input/output buffers passed alongside are byte-identical after every call
  (no mutation); recording still works while open (declare => `Ok`).
- EXT-008-T05 (no host/side-effect safety): run full matrix while asserting
  no child process spawned, no files outside the disposable test dir, no DB
  writes; captured logs contain zero filter strings beyond the label and
  zero credential-like bytes; gate-ever-opened test asserts still zero
  handler invocations via a counter the (absent) executor would have hit.
