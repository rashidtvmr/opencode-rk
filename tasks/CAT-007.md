Status: IMPLEMENTED. Kind: product. Runtime optional: False.

## User-observable outcome

An in-memory event bus allowing decoupled event-driven notifications across
catalog subsystems. Supports the four catalog event variants plus subscription
management with a hard subscriber cap.

- crates/catalog/src/lib.rs line 4 (`pub mod events;`): module pre-wired.

## Observable contract

- `CatalogEvent` enum variants:
  - `PluginLoaded { plugin_id: String }`
  - `PluginUnloaded { plugin_id: String }`
  - `PluginError { plugin_id: String, error: String }`
  - `IndexUpdated { provider_count: usize, model_count: usize }`
- `CatalogEventBus::new() -> Self`
- `subscribe<F>(&self, handler) -> Result<SubscriptionId, EventBusError>` where
  `F: Fn(&CatalogEvent) + Send + Sync + 'static`
- `unsubscribe(&self, id: SubscriptionId) -> bool`
- `emit(&self, event: &CatalogEvent)`
- `stats(&self) -> (subscribers: usize, last_event: Option<String>)`
- `MAX_SUBSCRIBERS = 100`
- `EventBusError::MaxSubscribersReached`
