# SEC-012 - Advanced SQL classification

Status: DONE. Kind: product.
Dependencies: SEC-001 (`crates/security/src/lib.rs` authorize_sql baseline).
Ownership: crates/security/src/sql_classify.rs (new), crates/security/src/lib.rs (mod line only).

## Outcome
Standalone `SqlClassifier` with configurable strictness. Complements broker `authorize_sql`, does not alter it. Verdicts: `Safe`, `NeedsReview(reason)`, `Denied(reason)`.

## Rules
- Denied (mandatory, all strictness levels): GRANT/REVOKE, ATTACH DATABASE, `.import`/`.load`.
- NeedsReview (gated by strictness): CREATE/DROP INDEX, UPDATE without WHERE, INSERT INTO ... SELECT, write PRAGMAs, multi-statement (`;`).
- Safe: plain SELECT, UPDATE with WHERE, read PRAGMAs (`PRAGMA name` / `PRAGMA fn(args)` without `=`), single-value INSERT.
- Strictness: Permissive (review->Safe), Standard (review stays), Strict (review->Denied). Denied never downgraded.
- Write PRAGMA = contains `=` OR maintenance call WAL_CHECKPOINT/SHRINK_MEMORY/OPTIMIZE.
