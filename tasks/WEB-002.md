## User-observable outcome

Domain failures from the control-plane service surface to HTTP callers as a
stable, versioned error shape with correct status codes, translated exactly at
the route boundary. Domain/storage services stay free of HTTP types. A browser
or CLI caller can distinguish not-found, conflict, and internal failures without
parsing free text. `web/` browser code is owned elsewhere; this card specifies
the server-side translation contract only.

## Observable contract

- New additive Rust boundary: `crates/server/src/control_plane_errors.rs`
  (suggested; worker ships additive fragment only, never edits shared `lib.rs`,
  `Cargo.toml`, schemas, migrations; integrator wires).
- `DomainError { SessionNotFound, TargetExists, TargetUnreadable, ConflictOrLocked, Internal }`
  (domain-only enum; no `http`, `StatusCode`, or JSON imports in the domain type).
- `translate(err: &DomainError) -> HttpError { status: u16, code: &'static str, message: String }`
  mapping (frozen):
  `SessionNotFound => (404, "session_not_found")`,
  `TargetExists => (409, "target_exists")`,
  `TargetUnreadable => (422, "target_unreadable")`,
  `ConflictOrLocked => (409, "conflict_or_locked")`,
  `Internal => (500, "internal")`.
- `message` is a fixed redacted template per variant (no paths, no secrets, no
  inner I/O strings); wire JSON is exactly
  `{ "error": { "code": <code>, "message": <template> } }`.
- Translation is pure and total: every `DomainError` variant maps to exactly one
  `(status, code)` pair; exhaustive `match` (no wildcard fallback that could hide
  a new variant; adding a variant is a compile break, asserted by test).
- Domain service signature stays HTTP-free: `fn move_session(input) -> Result<Outcome, DomainError>`.

## Failure states

- Unknown/new domain variant: compile-time exhaustiveness failure, never a silent
  500 remap; test asserts all variants covered (`assert_eq!(all_codes().len(), 5)`).
- Internal error: `500/internal` with redacted template; inner cause never serialized
  (`assert!(!body.contains(inner_secret))`).
- Double translation (translating an already-`HttpError`): rejected by types
  (`translate` takes only `&DomainError`); test asserts no `HttpError -> HttpError` impl exists
  (compile-fail fixture or missing-trait assertion per harness).
- Secret safety: messages contain zero filesystem paths, zero secret bytes;
  tests use disposable fixtures; no user OpenCode DB writes; no network.

## Resource bounds

- Translation allocates at most one small fixed template string per call; message
  length capped at `MAX_ERROR_MESSAGE_BYTES = 512` (`assert!(body.len() <= 2048)` total).
- No queue, thread, task, clock, watcher, retry, or background finalizer.
  Pure synchronous mapping over caller-owned error; output owned, bounded.
- Owner/cancel path: none needed (synchronous, bounded); caller owns lifetimes.
- Error cardinality fixed: 5 variants today; growth requires explicit contract update.
