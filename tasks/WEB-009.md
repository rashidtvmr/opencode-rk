# WEB-009 - Structured reasoning, tool activity and references

Status: NOT STARTED. Kind: product. Runtime optional: False.
Mandatory for full declared release: yes.
Requirements: REQ-040.
Dependencies: provider turn stream; V2 execution/tool persistence.
Test obligations: WEB-009-T01, WEB-009-T02, WEB-009-T03, WEB-009-T04, WEB-009-T05.

## User-observable outcome

Assistant turns display final answer text separately from collapsed Reasoning summary,
collapsed Tool calls/activity and a dedicated References/Sources section.

## Safety boundary

"Reasoning" means provider-supplied reasoning summary or OpenCode RK's own auditable
activity records. Raw hidden chain-of-thought is never requested, persisted or shown.

## Observable contract and tests

- **WEB-009-T01 — structured stream:** real reasoning-summary deltas, tool lifecycle
  records, final answer text and answer references are projected into distinct parts
  and reconcile to one persisted turn.
- **WEB-009-T02 — malformed/unsupported activity:** unknown or malformed provider tool
  or reasoning events fail explicitly/boundedly and never become fabricated final
  answer content.
- **WEB-009-T03 — accessibility:** Reasoning and Tool sections are collapsed controls
  with correct expanded state; streaming does not announce every delta; References
  are navigable with meaningful source labels.
- **WEB-009-T04 — resource/cancellation bounds:** event counts, payload sizes and
  accumulated summaries are bounded; browser disconnect cancels upstream/provider
  work and releases the shared turn permit.
- **WEB-009-T05 — persisted fidelity:** reload reproduces the same final answer,
  reasoning summary, tool states and references without storing hidden CoT.
