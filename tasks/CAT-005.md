## Observable contract

- `SearchIndex`: has `entries: Vec<CatalogEntry>`, `indexed_count: u64`.
- `index(entry: CatalogEntry)`: adds entry, increments indexed_count.
- `search(query: &str) -> Vec<&CatalogEntry>`: case-insensitive match on name, tags, or description (if present).
- `clear()`: removes all entries, resets indexed_count to 0.
- `stats() -> (usize, u64)`: returns (entries.len(), indexed_count).
