# DB-006: Storage Migration Runner

## Status
DONE

## Summary
Implemented a schema migration runner in `crates/storage/src/migrations.rs` with:
- `Migration` struct: version, name, sql, checksum (blake3)
- `AppliedMigration` struct: version, applied_at, checksum
- `MigrationRunner`: takes `&mut Connection`, manages `_migrations` table
- `run_pending()`: runs unapplied migrations in version order within a single transaction
- `applied()`: lists applied migrations from `_migrations` table
- `verify_checksums()`: detects tampered migrations by comparing stored vs computed checksums

## Tests (all 5 passing)
1. `empty_db_runs_all` - fresh DB, all 3 migrations run
2. `skip_already_applied` - second run skips already-applied
3. `checksum_mismatch_fails` - tampered checksum detected
4. `ordered_execution` - unordered migrations run in version order
5. `partial_failure_rolls_back` - failing migration rolls back entire transaction (atomic)
