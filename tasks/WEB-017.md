# WEB-017 - Editable writing and code artifacts

Status: NOT STARTED. Kind: product. Runtime optional: False.
Mandatory for full declared release: yes.
Requirements: REQ-040.
Dependencies: message-part/artifact storage and safe native execution/apply boundaries.
Test obligations: WEB-017-T01, WEB-017-T02, WEB-017-T03, WEB-017-T04, WEB-017-T05.

## User-observable outcome

Assistant-created long-form writing and code can open as dedicated editable artifacts
with copy/edit/undo/preview and, for code, explicitly authorized safe run/apply
actions rather than being trapped in plain transcript text.

## Observable contract and tests

- **WEB-017-T01 — artifact happy path:** structured writing/code output becomes a
  persisted artifact part that can be edited/copied and previewed without mutating the
  original assistant message silently.
- **WEB-017-T02 — execution/apply safety:** preview/run/apply is disabled when no safe
  native executor exists and remains subject to normal permission/destructive-action
  policy when enabled.
- **WEB-017-T03 — accessibility:** artifact editor/preview toggles, code controls and
  undo/redo are keyboard/screen-reader operable with preserved focus/selection.
- **WEB-017-T04 — bounds:** document size, preview work and execution output are
  bounded/cancellable and do not retain unbounded editor history.
- **WEB-017-T05 — version/reload fidelity:** artifact edits create explicit versions
  or drafts and survive reload without rewriting historical assistant output.
