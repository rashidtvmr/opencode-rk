## User-observable outcome

Native integration metadata can be registered in nested scopes, overridden and revealed again when a scope closes, while OAuth authorization attempts have a bounded caller-driven pending/complete/expired/cancel lifecycle. This slice never stores secret key/access/refresh material and performs no network or HTTP work.

## Observable contract

- Scoped registration is bounded, deterministic, and last-scope-wins; closing an override reveals the prior registration rather than deleting it.
- Integration methods are metadata only (`key`/`oauth`) and replacement is deterministic; no raw secret is retained.
- OAuth attempts use caller-supplied ids/time, a fixed ten-minute expiry, bounded active-attempt count, and typed duplicate/overflow/not-found/code-required outcomes.
- Missing authorization code leaves a code-mode attempt pending and non-mutated; successful completion returns only non-secret integration/method/label metadata for the caller to persist elsewhere.
- Cancel removes a pending attempt; explicit expiry marks overdue pending attempts expired without a clock thread/background scrubber.
