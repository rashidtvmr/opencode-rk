## Implementation

Created `crates/storage/src/rollout_v2.rs` with:

### RolloutRecord
```rust
pub struct RolloutRecord {
    pub id: String,
    pub timestamp_us: i64,
    pub event_type: String,
    pub payload_json: String,
}
```

### RolloutRecorder
- `new(jsonl_path, conn)` - creates `_rollout_events` table, opens JSONL for append
- `append(record)` - writes to JSONL first (truth), then INSERT into sqlite
- `query_by_type(event_type, limit)` - returns Vec<RolloutRecord> from sqlite
- `replay_from_jsonl(path)` - reads JSONL, returns Vec<RolloutRecord>
- `verify_consistency()` - returns Result<bool> comparing JSONL lines vs sqlite rows

### Tests (5 tests using tempfile + in-memory conn)
1. `append_and_query` - writes 3 records, queries by type, verifies correct filtering
2. `jsonl_is_truth` - writes JSONL, corrupts sqlite, replay_from_jsonl still recovers records
3. `replay_matches` - appends 3 records, replays from JSONL, all 3 match
4. `consistency_check` - appends 2 records, verify returns true
5. `query_by_type_filters` - tests filtering by event_type with limits
