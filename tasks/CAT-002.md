# CAT-002 - Catalog configuration management

Status: COMPLETE. Kind: feature.
Requirements: opencode.catalog-config.
Ownership locks: crates/catalog/src/config.rs, this card.
Suggested module: `crates/catalog/src/config.rs` (bounded only).

## User-observable outcome

Typed configuration structure for the catalog subsystem. Enables
setting directory paths, auto-reload behavior, refresh intervals,
and remote source permissions via TOML configuration files.

## Source evidence

- `crates/catalog/Cargo.toml`: serde, serde_json, toml workspace deps added.
- `crates/foundation/src/config.rs` lines 363-369: TOML/JSON parsing pattern.
- `crates/storage/Cargo.toml`: tempfile dev-dependency for test isolation.

## Observable contract

- `CatalogConfig` struct with:
  - `catalog_dir: PathBuf` - directory for catalog entries
  - `auto_reload: bool` - enable filesystem watch reload
  - `refresh_interval_secs: u64` - polling interval
  - `max_entries: usize` - entry limit
  - `allow_remote: bool` - remote source permission

- `Default impl` with:
  - `catalog_dir: PathBuf::from("catalogs")`
  - `auto_reload: true`
  - `refresh_interval_secs: 30`
  - `max_entries: 1000`
  - `allow_remote: false`

- `load(path: &Path) -> Self` - parses TOML if exists, returns Default otherwise
- `save(&self, path: &Path) -> std::io::Result<()>` - writes TOML to file
- `validate(&self) -> Result<(), String>` - returns Err if max_entries == 0

## Failure states

- `load` returns Default if file missing or parse error.
- `save` returns std::io::Error on write failure.
- `validate` returns Err with message if max_entries is 0.
